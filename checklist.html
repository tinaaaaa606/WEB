POS Computer Preparation Checklist

**Computer/Station ID:** **Technician:** **Date Completed:**

*Note: Configuration steps can generally be done in any order, but system resets or reinstalling Windows should be performed first if necessary.*

I. Initial System Setup & Windows Updates

StepTask DescriptionCompletedConfiguration Detail / Command
**I.1**Reset PC or Reinstall Windows (if needed)Must be the first step if performed.
**I.2**Create Local Windows AccountUse a **local Windows account** (not tied to email).
**I.3**Set Local Windows User NameLocal Windows user account will always be **“POS”** on all computers.
**I.4**Update WindowsUpdate Windows until it is up-to-date.
**I.5**Skip Optional UpdatesSkip “Optional Updates”.

II. Core System Identification & Control

StepTask DescriptionCompletedConfiguration Detail / Command
**II.1**Change Computer NameChange computer name accordingly.
**II.2**Change Workgroup NameAlso change **“Workgroup”** name to **“WAWIO”** (computer may require a restart).
**II.3**Configure Security and MaintenanceUncheck all boxes under “Change Security and Maintenance Settings,” except for **“Network firewall”**.
**II.4**Configure User Account Control (UAC)Drop the slider all the way to the bottom (to "Never notify").

III. Windows Settings Configuration

StepTask DescriptionCompletedConfiguration Detail / Command
**III.1**System > Notifications & actions**Turn off or uncheck all possible options**.
**III.2**Power & Sleep (Screen)Turn off screen after **1 hour** (when plugged in).
**III.3**Power & Sleep (Sleep)Set PC to **“Never sleep”** (when plugged in).
**III.4**Additional Power Settings (Buttons)Set power button to **“Do nothing”** on all possible options.
**III.5**Tablet Mode (Sign In)Set “When I sign in” to **“Never use tablet mode”**.
**III.6**Tablet Mode (Usage)Set “When I use this device as a tablet” to **“Don’t switch to tablet mode”**.
**III.7**Multitasking**Turn off or uncheck all possible options**.
**III.8**Network & Internet PropertiesSet properties to **“Private”**.
**III.9**Set Static IP AddressSet static IP address if necessary.
**III.10**Desktop IconsCheck only **“Computer”** and **“Recycle Bin”**.
**III.11**Taskbar HidingSet **“On”** for automatically hide the taskbar in desktop mode.
**III.12**Taskbar Notification Area (Visible Icons)Set **“On”** only for **“Network”**.
**III.13**System IconsSet **“On”** for Clock, Network, Input Indicator, and Touch keyboard; set everything else **“Off”**.

IV. Application Installation and File Management

StepTask DescriptionCompletedConfiguration Detail / Command
**IV.1**Install Google Chrome & Set Default BrowserDownload and install Google Chrome (if not done already). Change the default web browser to **“Google Chrome”**.
**IV.2**Install Remote Access (Primary)Download and install **Teamviewer** and add the computer to the support account.
**IV.3**Install Remote Access (Secondary)Download and install **Supremo** and add the computer to the support account (if this station has RDP).
**IV.4**Move Data in Drive D:Move Data in Drive D: to the Document folder.
**IV.5**Configure Chrome DownloadsSetup Chrome Download to “Ask where to save each file before downloading”.
**IV.6**Create wSupport FolderCreate a folder named **“wSupport”** under D:/ drive (or C:/ drive if D:/ drive is not available).
**IV.7**Download Softwares to wSupportDownload Fonts, 4SoftSetup, Printer Driver, Net Framework.
**IV.8**Install Fonts (Step 1: Install)**Extract files** within the “Fonts” folder, and then **Install all of the Fonts**.
**IV.9**Install Fonts (Step 2: For All Users)Second, install the fonts **for all users**.
**IV.10**Adjust Desktop Icons / TaskbarAdjust icons on the screen to be clear, clean, and easy to use. Unpin other icons at the taskbar.

V. Advanced Configuration (Time, Security, & Updates Control)

StepTask DescriptionCompletedConfiguration Detail / Command
**V.1**Set Time ZoneChange “Time zone” according to the area of the restaurant.
**V.2**Sync TimeRecommended to Sync time with Internet time at least once.
**V.3**Add Thai LanguageAdd Thai language if not already included.
**V.4**Verify Firewall StatusMake sure “Firewall & network protection” is active on all network types.
**V.5**Disable Reputation-based ProtectionApp & Browser control > Reputation-based protection set to **“Off”** and uncheck all possible options.
**V.6**Disable Automatic Updates (Group Policy)Run `gpedit.msc`. Set “Configure Automatic Updates” to **Disabled**.
**V.7**Remove Update Access (Group Policy)Run `gpedit.msc`. Set “Remove access to use all Windows Update features” to **Enabled**.
**V.8**Disable Login PasswordRun `netplwiz`. **Uncheck** “User must enter a user name and password to use this computer”.
**V.9**Disable Windows Update ServiceRun `services.msc`. Find “Windows Update,” set **Startup type** to **Disabled**, and click **Stop**.

VI. Printer Station Setup

StepTask DescriptionCompletedConfiguration Detail / Command
**VI.1**Install Printer DriverDownload files and install the suitable driver for the devices.
**VI.2**Set Default PrinterManage and set the required printer as default.
**VI.3**Rename PrinterRename the printer using the format: Name(No.)\_type of connection\_Fourth Octet (if by LAN), e.g., `RECEIPT01_USB`.
**VI.4**Adjust Paper SizeOpen “Preference” and **adjust the paper size** suitable for the printer.
**VI.5**Print Test PagePrint a Test Page for testing print functionality.

4Soft Installation Checklist

**Computer/Station ID:** **Technician:** **Date Completed:**

*Note: This checklist assumes preparatory steps (naming, networking, disabling updates, etc.) have been completed.*

A. Database Server Station Checklist

StepTask DescriptionCompletedConfiguration Detail / Command
**A.1**Set Computer Name and RestartSet *Computer Name*. Max 15 characters, not same as User Name.
**A.2**Install Required RuntimesInstall .NET 6.0.16 (ASP.NET Core & Windows Desktop) and .NET 4.7.2.
**A.3**Install SQL ServerInstall `SQLServer_86_x64 for 4Soft Rev3.exe`.
**A.4**Restart Computer (After SQL)Restart the computer after step A.3.
**A.5**Run 4Soft Setup (Database Creation)Run `4SoftSetup.exe`. Check “**Create Blank Database**,” then click “Install”.
**A.6**Place Startup File (Print Server)Place correct `.bat` file into the Windows startup folder.
**A.7**Run Server ConfigRun `server-config` as administrator from the 4Soft bin directory.
**A.8**Configure Server ConnectionEnter the Database Server's **Computer Name** and click “Save”.
**A.9**(OPTIONAL) Restore DatabaseIf restoring, run `DatabaseTools.exe` and use the restore function.
**A.10**Run Activation ToolRun `activate` as administrator from the 4Soft bin directory.
**A.11**Activate Main POS LicenseEnter the main serial number in both fields and click “Add POS”.

B. Client Station Checklist

StepTask DescriptionCompletedConfiguration Detail / Command
**B.1**Set Computer Name and RestartSet a unique Computer Name (different from server).
**B.2**Install Required RuntimesInstall .NET 6.0.16 (ASP.NET Core & Windows Desktop) and .NET 4.7.2.
**B.3**Run 4Soft Setup (Client Installation)Run `4SoftSetup.exe`. **Leave “Create Blank Database” unchecked**, then “Install”.
**B.4**Run Server ConfigRun `server-config` as administrator from the 4Soft bin directory.
**B.5**Configure Server ConnectionEnter the **Database Server's Computer Name** and click “Save”.
**B.6**Run Activation ToolRun `activate` as administrator from the 4Soft bin directory.
**B.7**Activate Client POS LicenseEnter main serial and client POS serial, then click “Add POS”.

RDP Local Setup Checklist

**Main DB Server PC:** **Technician:** **Date Completed:**

*Note: This checklist covers setting up an iPad for RDP access to a local server.*

Part 1: iPad Initial Setup

StepTask DescriptionCompletedConfiguration Detail / Command
1.1Create Apple IDGo to Settings > Sign in. Tap "Don't have an Apple ID?" > Create Apple ID.
1.2Enter DetailsName: **Wawio Support**, DOB: **01/01/1981**.
1.3Create iCloud EmailSelect "get a free iCloud email address". Use restaurant name for the email.
1.4Set PasswordUse the restaurant's name and its street address for the password.
1.5Configure App Store AccountOpen App Store. When prompted, review account, select payment method **"None"**, and fill in the billing address.

Part 2: Install and Setup TS-Plus Software

StepTask DescriptionCompletedConfiguration Detail / Command
2.1Download & Install TSPlusGo to `tsplus.net/download/` and install **TSPlus Remote Access**. Decline Java install and initial reboot.
2.2Change RDP PortRun AdminTool > HOME > Change RDP port. Set port to **9559**. Decline reboot.
2.3Disable Time Zone RedirectionAdminTool > SESSION > Setting > Uncheck **Enable Time Zone Redirection**.
2.4Disable Time Zone Redirection (GPO)Use the link in TSPlus to open `gpedit.msc`. Set "Allow time zone redirection" to **Disabled**.
2.5Create Tablet UsersAdminTool > SESSION > Client Generator > User and Groups. Create users (e.g., **TAB01**) with password that never expires.
2.6Assign Admin RightsOpen each new user's properties and add them to the **Administrators** group.
2.7Add Firewall RuleAdd an Inbound rule in Windows Firewall for **TCP Port 9559**.
2.8Reboot ServerUse the AdminTool > SYSTEM TOOLS menu to **Reboot the Server**.

Part 3: Setup RDP Client on iPad

StepTask DescriptionCompletedConfiguration Detail / Command
3.1Download Jump DesktopDownload **Jump Desktop** from the App Store.
3.2Create New ConnectionOpen the app, tap **+**. Host: **IP Address of Main DB Server**. Port: **9559**.
3.3Configure AutologonEdit the connection properties and enter the login credentials for the tablet user (e.g., TAB01).
3.4Configure Touch OptionsWhile connected, open the top menu. Change Touch option to **Pen** and turn off **Show Pointer**.
3.5Create 4Soft ShortcutIn the RDP session, navigate to `C:\Program Files (x86)\4Soft POS\bin`. Create a desktop shortcut for `4softremote`.
3.6Rename & Configure ShortcutRename shortcut to **"4Soft Tab"** and set it to **always run as administrator**.
3.7Activate RDP LicenseRun the `activate` application and select **Add 4Soft POS** to activate the RDP license.
