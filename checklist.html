POS Computer Preparation Checklist

**Business Name:**
**Computer/Station ID:** **Technician:** **Date Completed:**

*Note: Configuration steps can generally be done in any order, but system resets should be performed first.*

I. Initial System Setup & Windows Updates

StepTask DescriptionCompletedConfiguration DetailRemark
**I.1**Reset PC or Reinstall Windows (if needed)Must be the first step if performed.
**I.2**Create Local Windows AccountUse a **local Windows account** (not tied to email).
**I.3**Set Local Windows User NameLocal Windows user account will always be **“POS”**.
**I.4**Update WindowsUpdate Windows until it is up-to-date.
**I.5**Skip Optional UpdatesSkip “Optional Updates”.

II. Core System Identification & Control

StepTask DescriptionCompletedConfiguration DetailRemark
**II.1**Change Computer NameChange computer name accordingly.
**II.2**Change Workgroup NameChange **“Workgroup”** name to **“WAWIO”** (may require restart).
**II.3**Configure Security and MaintenanceUncheck all boxes, except for **“Network firewall”**.
**II.4**Configure User Account Control (UAC)Drop the slider to the bottom ("Never notify").

III. Windows Settings Configuration

StepTask DescriptionCompletedConfiguration DetailRemark
**III.1**System > Notifications & actions**Turn off or uncheck all possible options**.
**III.2**Power & Sleep (Screen)Turn off screen after **1 hour** (when plugged in).
**III.3**Power & Sleep (Sleep)Set PC to **“Never sleep”** (when plugged in).
**III.4**Additional Power Settings (Buttons)Set power button to **“Do nothing”**.
**III.5**Tablet Mode (Sign In)Set “When I sign in” to **“Never use tablet mode”**.
**III.6**Tablet Mode (Usage)Set “When I use this device as a tablet” to **“Don’t switch”**.
**III.7**Multitasking**Turn off or uncheck all possible options**.
**III.8**Network & Internet PropertiesSet properties to **“Private”**.
**III.9**Desktop IconsCheck only **“Computer”** and **“Recycle Bin”**.
**III.10**Taskbar HidingSet **“On”** for automatically hide the taskbar.
**III.11**Taskbar Notification AreaSet **“On”** only for **“Network”**.
**III.12**System IconsSet **“On”** for Clock, Network, Input Indicator, Touch keyboard; others **“Off”**.

IV. Application Installation and File Management

StepTask DescriptionCompletedConfiguration DetailRemark
**IV.1**Install Chrome & Set DefaultInstall and set Google Chrome as default browser.
**IV.2**Install Remote Access (Primary)Install **Teamviewer** and add to support account.
**IV.3**Install Remote Access (Secondary)Install **Supremo** and add to support account (if station has RDP).
**IV.4**Create wSupport FolderCreate **“wSupport”** folder under D:/ drive (or C:/).
**IV.5**Download Softwares to wSupportDownload Fonts, 4SoftSetup, Printer Driver, Net Framework.
**IV.6**Install FontsExtract and install all fonts, then install **for all users**.

V. Advanced Configuration

StepTask DescriptionCompletedConfiguration DetailRemark
**V.1**Set Time ZoneChange Time zone according to the restaurant's area.
**V.2**Verify Firewall StatusMake sure Firewall is active on all network types.
**V.3**Disable Reputation-based ProtectionApp & Browser control > Reputation-based protection set to **“Off”**.
**V.4**Disable Automatic Updates (GPO)`gpedit.msc` > Set “Configure Automatic Updates” to **Disabled**.
**V.5**Remove Update Access (GPO)`gpedit.msc` > Set “Remove access to all Windows Update features” to **Enabled**.
**V.6**Disable Login Password`netplwiz` > **Uncheck** “User must enter a user name...”.
**V.7**Disable Windows Update Service`services.msc` > Find “Windows Update,” set **Startup type** to **Disabled**, and **Stop** service.

VI. Printer Station Setup

StepTask DescriptionCompletedConfiguration DetailRemark
**VI.1**Install Printer DriverInstall suitable driver for the devices.
**VI.2**Set Default PrinterManage and set the required printer as default.
**VI.3**Rename PrinterFormat: `RECEIPT01_USB`.
**VI.4**Adjust Paper SizeOpen “Preference” and adjust paper size.
**VI.5**Print Test PagePrint a Test Page to test functionality.

Part 2: Install and Setup TS-Plus

StepTask DescriptionCompletedConfiguration DetailRemark
2.1Download & Install TSPlusInstall **TSPlus Remote Access** from `tsplus.net`. Decline Java & initial reboot.
2.2Change RDP PortAdminTool > HOME > Change RDP port to **9559**. Decline reboot.

2.4Create Tablet UsersAdminTool > SESSION > Client Generator. Create users (e.g., **TAB01**).
2.5Assign Admin RightsAdd new users to the **Administrators** group.
2.6Add Firewall Rule & RebootAdd Inbound rule for **TCP Port 9559**. Reboot server via AdminTool.

StepTask DescriptionCompletedConfiguration DetailRemark
